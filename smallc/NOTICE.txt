Upstream credits Ron Cain, James E. Hendrix, Chris Lewis, and subsequent
contributors; source notices are retained. See upstream/LICENSE for the full
public-domain dedication/Unlicense and disclaimer. The existing 8080 backend,
CP/M runtime, archives, and executables are not bundled or used.

build.py makes build-directory copies with standard C library includes,
explicit int main, a return value on doAnsiArguments' success path, and
a prototype for init (its fifth argument must be a pointer on Windows x64). It
links these to the newly authored code8008.c, rather than code8080.c.
The operation renderer, RAM-stack runtime, console support, examples, scripts,
and tests are project contributions. The runtime is adapted from this
project's ACK/8008 runtime; it does not incorporate the ACK upstream runtime.
