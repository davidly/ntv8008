prepare.py translates the AS assembler dialect and adapts the console for
ntv8008. It removes the author's development-only example autoloader and
the run-loop keyboard poll. It relocates code around the fixed restart
vectors and supplies the default 0x40 entry. No language features, numeric
types, program storage formats, or expression rules have been added.
