Pascal integration (2026-10-29): bootstrap also builds ACK's em_pc frontend.
A build-source patch makes negative constant MOD agree with Pascal's runtime
(nonnegative remainder for positive divisors) and rejects nonpositive constant
MOD divisors. The original pinned archive/checksum and upstream notices remain
unchanged. ack/pascal.py, pascal/runtime.c, pascal/runtime.asm, examples and
integration scripts/tests are new project contributions. The hosted upstream
libpc sources, binaries and their historical runtime headers are not bundled.

Modula-2 integration (2026-10-30): the existing pinned ACK source also supplies
its Modula-2 frontend under ACK's existing licensing terms. The new InOut
subset and console shim are original project code, sharing this project's
Pascal array/static-link support. No historical libm2 runtime is linked or
redistributed in the program images. No additional third-party source archive
or license dependency is introduced.

ACK BASIC integration (2026-10-30): the existing pinned ACK archive supplies
its BASIC frontend under the ACK source distribution's existing terms. The
new console/integer/GOSUB runtime and examples are project code; TTT adapts
this project's existing SCELBAL example. Shared array support is this project's
Pascal runtime. No historical BASIC runtime library is linked or redistributed
in the generated images. Target-specific compiler changes and bug fixes are
recorded in ack/basic/patch.py and applied to cached source by bootstrap.py;
the verified original archive remains unchanged. No new third-party dependency
or license is introduced.
