locally by a user, they are kept verbatim in the ignored upstream/ directory. prepare.py produces
an adapted, macro-expanded source in ../a08/forth.asm; it is not upstream's
original file. See README.md for the console adaptations and bug fixes.

Examples e.f and ttt.f adapt David Lee's E.F and TTT.F in
cpm_compilers/DX-FORTH for CPM 4.56; sieve.f uses the same classic odd-number
sieve with packed flags. cpm_compilers identifies the author's benchmark
code as CC0-1.0, separately from the historical CP/M compiler/interpreter.
No DX-FORTH executable, kernel source or runtime is incorporated here.

The native.inc extension contains project additions for logical shifting and
packed-bit access, inserted by prepare.py. It does not modify the pinned
upstream files or change the provenance of the adapted kernel.
